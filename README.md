# BED Map

Interactive map of BEDucator Program adoption across Burning Man theme camps, by the Bureau of Erotic Discourse (BED).

**Live map:** https://MorganCKellar.github.io/brc-bed-map/

## Privacy

The published dataset (app/src/data/camps-snapshot.json) contains ONLY camp name, address, and BED status. No personal information is ever committed to this repository.

## Status colors

- Orange - Registered for the BEDucator Program
- Purple - Consent Policy adopted
- Pink - Fully BEDucated (BED Talk)

## Updating the map

Edit app/src/data/camps-snapshot.json and commit to main. GitHub Actions rebuilds and deploys automatically.

Learn more at https://bedtalks.org
